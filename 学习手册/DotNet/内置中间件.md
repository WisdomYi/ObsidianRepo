## 静态文件中间件

提供静态文件的访问支持 默认从wwwroot目录读取

``` 
app.useStaticFiles();
扩展：
app.UseFileServer(enableDirectoryBrowsing:true) //允许浏览目录结构
```

## 路由中间件

处理请求路由匹配，映射请求到控制器、Razor页面、端点。

```
app.UseRouting();   //启用路由匹配
app.UseEndpoints(endpoints =>{ //端点路由配置，与路由中间件配合，必须在UseRouting之后配置。
endpoints.MapControllers();
endpoints.MapRazorPages();
endpoints.MapGet("/hello",()=>"Hello World")
})
//可使用顶级引用
app.MapControllers();
app.MapRazorPages()

```

## Https中间件

自动重定向到https，强制使用加密连接。

```
builder.Services.AddHttpsRedirection(options=>{
options.HttpsPort = 5001;
})

app.UseHttpsRedirection();
```

## Cors中间件

处理跨域请求，允许指定外部域名访问当前服务。

```
builder.Services.AddCors(options =>{
options.AddPolicy("AllowFrontend",policy =>{
policy.WithOrigins("https://example.com")
		.AllowMethods("Get","Post")
		.AllowHeaders("Content-Type")
})
})

app.UseCors("AllowFrontend")
```

## 认证中间件

处理用户身份验证

```
// 注册认证服务（以JWT为例） 
builder.Services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme) 
.AddJwtBearer(options => {
// 配置JWT验证参数 
}); 
var app = builder.Build(); 
app.UseAuthentication();// 启用认证（需在授权之前） 
app.UseAuthorization(); // 启用授权（依赖认证结果）
```
